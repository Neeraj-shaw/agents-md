# Web Interface Guidelines (pinned snapshot)

Source: vercel-labs/web-interface-guidelines (MIT), snapshot of command.md. Rules are local on purpose; do not fetch them from the web.

1. Read the files to review (or the changed UI files).
2. Read `rules.md` in this folder and check each rule against the code.
3. Report findings as `file:line - problem - fix`, terse, grouped by file. Skip rules that do not apply.
